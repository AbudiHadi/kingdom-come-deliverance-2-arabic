## التثبيت: النسخ اليدوي (دقيقتان)

> **عندك إصدار سابق من التعريب؟** نفس الخطوات: استبدل الملفات بالجديدة مباشرة.

### 1) حمّل الملف

حمّل الملف المضغوط `KCD2-Arabic-Manual.zip` (15 ميجابايت) وفك الضغط عنه:

<div align="center">

### [⬇ KCD2-Arabic-Manual.zip](https://github.com/AbudiHadi/kingdom-come-deliverance-2-arabic/raw/main/download/KCD2-Arabic-Manual.zip)

</div>

### 2) افتح مجلد اللعبة

في Steam: اضغط بزر الفأرة **الأيمن** على اللعبة في المكتبة ← **Manage** ← **Browse local files**.

### 3) احفظ نسخة احتياطية (لا تتخطَّ هذه الخطوة)

انسخ الملفات التالية إلى مكان آمن خارج مجلد اللعبة: —

### 4) انسخ ملفات التعريب

1) انسخ `Localization/Arabic_xml.pak` إلى `Localization` (ملف جديد، لا يوجد أصل له).
2) انسخ `Mods/arabic/mod.manifest` إلى `Mods ← arabic` (ملف جديد، لا يوجد أصل له).
3) انسخ `Mods/arabic/Data/arabic.pak` إلى `Mods ← arabic ← Data` (ملف جديد، لا يوجد أصل له).

> **مهم جدًا:** يجب أن تكون أسماء الملفات **بالضبط** كما هي. ملف بجانب الأصلي باسم آخر **ستتجاهله اللعبة**.

### 5) شغّل اللعبة واختر العربية

```
الإعدادات ← لغة النصوص ← العربية
```

---

## كيف أرجع اللعبة إلى الإنجليزية؟

احذف الملفات الثلاثة التي نسختها (مجلد `Mods/arabic` والملف `Localization/Arabic_xml.pak`): لا يوجد ملف أصلي يستبدل. أو من Steam: زر الفأرة الأيمن على اللعبة ← **Properties** ←
**Installed Files** ← **Verify integrity of game files**.
